Question 6

In a classification report, explain the meaning of the following metrics:

Precision
Recall
F1 Score
Support
Accuracy

Answer:

A classification report is used to evaluate the performance of a classification machine learning model. It provides different metrics to understand how accurately the model predicts different classes.

1. Precision:
   Precision tells us how many of the samples predicted as positive are actually positive.

Precision = TP / (TP + FP)

In simple words, precision tells us how many of the positive predictions made by the model are correct.

2. Recall:
   Recall tells us how many of the actual positive samples are correctly identified by the model.

Recall = TP / (TP + FN)

In simple words, recall tells us how many of the actual positive samples were correctly found by the model.

3. F1 Score:
   F1 Score is the harmonic mean of precision and recall. It provides a balance between precision and recall.

F1 Score = 2 × (Precision × Recall) / (Precision + Recall)

A higher F1 Score indicates better performance.

4. Support:
   Support represents the number of actual samples belonging to each class in the dataset.

For example, if there are 50 actual positive samples, the support for the positive class is 50.

5. Accuracy:
   Accuracy tells us the percentage of total predictions that are correct.

Accuracy = (TP + TN) / (TP + TN + FP + FN)

In simple words, accuracy tells us how many predictions the model got correct out of all the predictions.

Conclusion:
Precision, recall, F1 Score, support, and accuracy are important metrics used to evaluate classification models and understand their performance for different classes.


| Metric        | Meaning                                    |
| ------------- | ------------------------------------------ |
| **Precision** | Predicted positive → how many are correct? |
| **Recall**    | Actual positive → how many are found?      |
| **F1 Score**  | Balance between precision and recall       |
| **Support**   | Number of actual samples                   |
| **Accuracy**  | Overall percentage of correct predictions  |
